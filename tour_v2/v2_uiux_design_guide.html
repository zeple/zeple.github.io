01 · Experience Principles

경험 설계 원칙

기능 수보다 판단 속도와 신뢰를 우선합니다.

1

추천이 먼저

처음부터 목록 19,000개를 보여주는 대신 오늘의 추천과 큐레이션을 1급 시민으로 둡니다.

2

검색은 항상 빠르게

모바일 검색창은 상단 고정. PC 검색은 전역 헤더에서 접근합니다.

3

지도는 맥락, 목록은 판단

지도는 위치 관계를 보여주고 목록/상세는 선택을 돕습니다. 지도 때문에 목록 상태가 사라지면 안 됩니다.

4

정보는 계층화

제목 → 핵심 메타 → 추천 이유 → 상세 설명. 모든 정보를 같은 굵기·같은 색으로 말하지 않습니다.

5

데이터는 정직하게

AI 추론, 원천 사실, 정보 없음 상태를 구분합니다. “모름”을 가짜 숫자로 채우지 않습니다.

6

브랜드는 행동에 일관되게

Primary CTA는 브랜드 오렌지로 통일. 카테고리 색은 태그·아이콘·마커에만 씁니다.

04 · Core Patterns

핵심 인터랙션 패턴

검색모바일은 항상 상단. 검색 입력 시 지도/조건보다 검색 결과를 우선 보여줍니다.
Bottom Sheetmin / peek / expanded 3단 유지. drag handle과 header 영역에 user-select:none, touch-action:none.
지도 이동사용자가 직접 움직인 경우에만 “이 지역에서 다시 찾기”를 노출. 프로그램matic panTo/setBounds는 재검색 억제.
목록 ↔ 지도카드 선택 시 marker highlight + map pan. marker 선택 시 해당 카드 scrollIntoView + selection state.
필터순서: 누구랑 → 상황 → 테마. 그룹 내부 OR, 그룹 간 AND. 조건 변경은 즉시 반영하고 CTA는 “결과 보기 (N곳)”.
카드 밀도기본 리스트는 가로형 약 120~140px 높이. 태그는 최대 2개. 방문 여부는 badge가 아니라 row state로.
상세 CTAPrimary: 길찾기(브랜드 오렌지). Secondary: 가봤어요. 저장은 별도 기능 정의 전까지 신규 추가하지 않음.

  7. 함께 들르기 좋은 곳

06 · Data Trust UX

신뢰할 수 있는 정보 표현

데이터 가용성보다 더 중요한 것은 사용자가 “어디까지 믿어도 되는지” 알 수 있게 하는 것입니다.

원천 사실

주소·공식 운영정보 등은 일반 정보로 표현. 필요 시 “업데이트 YYYY.MM” 보조 표기.

AI 추론

`AI 분석` 또는 `예상` 라벨을 사용. confidence가 낮으면 핵심 CTA 판단 근거로 쓰지 않음.

정보 없음

빈 공간이나 임의 추정 대신 “정보 없음 / 준비 중”을 정상 상태로 표현.

금지
실제 데이터가 없는데 “무료”, “1~2시간”, “주차 가능”처럼 확정적으로 보여주지 않습니다.
07 · States

예외 상태도 디자인의 일부

Loading지도/리스트 skeleton. 기존 결과를 갑자기 비우지 않음.
No Results“조건 하나를 완화하면 23곳을 더 볼 수 있어요.”처럼 recovery 제공.
Location Denied현재 지도 중심 기준 탐색으로 fallback + 권한 설정 안내.
Map Error목록 탐색은 유지. 지도만 재시도/오류 표시.
No Image카테고리 tone + icon + place name placeholder.
AI UnavailableAI 배지/추천 이유 일부 숨김. 원천 데이터만으로 UI 유지.
Visitedrow state와 체크. 추천에서는 자동 제외 정책 유지.
Restored Filters재방문 시 조건 칩을 목록 상단에 노출해 복원 사실을 명확히 함.
08 · Accessibility

접근성 기본선

Interaction

  • 모든 터치 타깃 최소 44×44px
  • 닫힌 조건 시트/비활성 상세에 inert 적용
  • 모달 open 시 focus 이동, close 시 trigger로 복귀
  • focus-visible 유지
  • prefers-reduced-motion 유지

Semantic Structure

  • 카드 전체를 role=button으로 만들지 않음
  • 장소 제목은 실제 deep link anchor
  • 후기/지도/공유 아이콘에 텍스트 라벨 제공
  • 색상만으로 테마/상태를 구분하지 않음
