🏕 캠핏 예약 도우미

캠핏 사이트 안에서 패널을 띄워 검색부터 예약 북마클릿 생성까지 진행합니다.

설치

아래 버튼을 북마크바로 드래그하세요.

🏕 캠핏 도우미

드래그가 안 되면 아래 전체를 복사해 북마크를 직접 만들고 URL 칸에 붙여넣으세요.

사용 순서

  1. 캠핏에 로그인한 상태에서 아무 페이지나 열기
  2. 북마크 🏕 캠핏 도우미 클릭 → 오른쪽에 패널이 열립니다
  3. Step 0 캠핑장 이름 검색 → 선택
  4. Step 1 구역 선택
  5. Step 2 날짜 지정 → 사이트 조회 → 원하는 순서대로 클릭 (누른 순서 = 우선순위)
  6. Step 3 인원·예약자 정보 입력 → 요금 후보 제안 → 금액 하나 선택
  7. 헤더의 서버 시간을 보고 지금 실행을 누르면 그 순간 실행됩니다. 타이머 날짜·시각을 정하고 ⏰ 타이머 실행을 누르면 그 시각(서버 시간)에 실행됩니다 (기다리는 동안 탭을 화면에 띄워 두세요)

요청마다 전송·응답 대기·결과(또는 10초 타임아웃)가 로그에 남습니다. 실패하면 다시 시도를 누르세요. 저절로 재시도하지는 않습니다.

확인되지 않은 부분
캠핏 API 응답 구조는 PDF 문서를 근거로 추정해 작성했습니다. 구역·사이트 목록이 비어 보이면 패널에 표시되는 응답 내용을 알려주시면 맞추겠습니다.

예약 실행 북마클릿은 실제로 예약을 확정합니다. 무통장(bank) 결제로 요청하며 확인창 없이 진행되므로, 날짜와 인원을 반드시 확인한 뒤 사용하세요. 멈추려면 콘솔에 stopCf().
