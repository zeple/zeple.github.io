캠핑 일정

0단계 · 사전 진입 대기열 생기기 전에

지정한 날짜로 예약 페이지에 즉시 들어갑니다. 오픈이 임박하면 대기열 페이지가 앞을 막으므로, 그전에 미리 들어가 두면 대기열을 건너뛸 수 있습니다. 타이머 없이 실행 즉시 이동합니다.

잔여 사이트가 없으면 진입이 막힙니다. 주말·성수기를 피해 평일로 잡으세요.

🚪 사전 진입

2단계 · 북마클릿 진입 후 클릭

아래 버튼을 북마크바로 드래그하세요. 두 번 누르면 예약이 끝납니다.

  1. 1번째 클릭 — 오픈 시각까지 대기했다가 조회 시작 (이미 지났으면 즉시). 빈자리가 날 때까지 0.6초 간격으로 자동 재조회하다가 잡히면 상세 페이지로 이동
  2. 2번째 클릭 — 차량번호·할인·약관 입력 → 저장 (확인창은 자동 승인)

오픈 전에 미리 눌러두면 됩니다. 재조회를 멈추려면 ⏹ 중단을 누르세요.

🏕 캠핑예약 ⏹ 중단

② 유저스크립트 Tampermonkey

오픈 시각 대기부터 예약 완료까지 전자동. 서버 시간에 맞춰 진입하므로 PC 시계가 어긋나 있어도 됩니다. 아래를 복사해 Tampermonkey 새 스크립트에 붙여넣으세요.

  1. 크롬에 Tampermonkey 확장 설치
  2. 대시보드 → + (새 스크립트) → 기존 내용 전부 삭제
  3. 위 코드 붙여넣기 → Cmd+S
미리 확인해 두세요
크롬 chrome://extensions → Tampermonkey 세부정보 → 사용자 스크립트 허용을 켜야 스크립트가 페이지에 주입됩니다. 이게 꺼져 있으면 아무 동작도 하지 않습니다.

예약일 전에 오픈 시각을 몇 분 뒤로 잡아 한 번 시험해 보시길 권합니다. 콘솔에 [캠핑] 로그가 뜨면 정상입니다.
