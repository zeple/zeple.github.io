# 캠핑장 예약 도구함

캠핑장 예약 오픈 시각에 맞춰 예약을 자동으로 시도하는 브라우저 도구 모음입니다.
GitHub Pages로 그대로 서빙됩니다. 진입점은 `index.html`.

| 도구 | 대상 | 형태 |
|---|---|---|
| `camfit.html` | [캠핏](https://camfit.co.kr) | 북마클릿 (사이트 위에 패널을 띄움) |
| `thankyou.html` | [땡큐캠핑](https://m.thankqcamping.com) | 스크립트 생성기 |

---

## 수정할 때 어디를 고치나

**이 부분만 기억하면 됩니다. 두 도구의 구조가 서로 다릅니다.**

### 캠핏 — `src/camfit-panel.js` 를 고치고 빌드

`camfit.html` 안의 북마클릿은 **빌드 산출물입니다. 직접 고치지 마세요.**
소스는 `src/camfit-panel.js` 하나뿐입니다.

```bash
# 1. src/camfit-panel.js 를 수정한 뒤
node build.js

# 2. 커밋 전 확인 (빌드를 잊었는지 검사)
node build.js --check
```

`build.js` 가 하는 일 — 주석·들여쓰기 제거 → `encodeURIComponent` →
`camfit.html` 의 `<a class="bm" href="javascript:...">` 에 주입 → 문법 검사.

### 땡큐캠핑 — `thankyou.html` 을 직접 고침

로직이 파일 안의 `<script>` 에 그대로 들어 있습니다. 별도 소스도 빌드도 없습니다.

## 구조

```
├── index.html                    허브 페이지
├── camfit.html                   캠핏 배포본 ← 빌드 산출물, 직접 수정 금지
├── thankyou.html                 땡큐캠핑 생성기 ← 여기가 원본
├── build.js                      camfit-panel.js → camfit.html
├── src/
│   └── camfit-panel.js           캠핏 패널 원본 ← 여기가 원본
└── tools/
    ├── check_campsite.py         땡큐캠핑 API 파라미터 점검 (기본 dry-run)
    └── thankqcamping.user.js     땡큐캠핑 Tampermonkey판 (설정 하드코딩)
```

## 동작 방식

두 도구 모두 같은 흐름입니다.

1. **서버 시계 동기화** — 응답의 `Date` 헤더로 PC 시계 오차를 보정합니다.
   왕복 지연의 절반을 더해 맞추므로, 로컬 시계가 틀려도 오픈 순간을 놓치지 않습니다.
2. **오픈까지 대기** — 긴 `setTimeout` 은 오차가 커서, 1초 전부터 20ms 간격으로 재확인합니다.
3. **우선순위대로 시도** — 지정한 사이트 순서대로 예약을 시도하고, 실패하면 다음 후보로.

캠핏 쪽은 여기에 더해 **금액을 미리 계산**해 둡니다. 오픈 순간에 `calculate` 를
호출하면 왕복 지연만큼 늦기 때문에, 구역 요금표(`charges`·`tempCharges`·`peakPeriods`)로
박별 요금을 직접 계산한 후보와 `calculate` 응답을 **동시에** 씁니다.

## 캠핏 — 페이지에 맞춰 자동으로 열립니다

북마클릿을 누른 위치의 URL(`/camp/{캠핑장ID}/{구역ID}`)을 읽어 단계를 건너뜁니다.

| 누른 곳 | 열리는 화면 |
|---|---|
| 캠핑장 상세 `/camp/{캠핑장ID}` | Step 1 구역 선택 (캠핑장 선택됨) |
| 구역까지 `/camp/{캠핑장ID}/{구역ID}` | Step 2 날짜·사이트 (구역까지 선택됨) |
| 그 외 페이지 | Step 0 캠핑장 검색 |

URL 의 구역을 목록에서 찾지 못하면 Step 1 에서 직접 고르도록 안내합니다.

캠핑장 이름은 `/proxy/api/v1/app/experiences/camp/{캠핑장ID}` 로 확인합니다
(`/v1` 이 아닌 proxy 경로라 `api()` 헬퍼 대신 직접 호출). 실패하면 화면의
`og:title`·`h1`·`<title>` 과 구역 응답을 차례로 훑고, 그래도 못 찾으면
이름 없이 진행합니다 — 표시용이라 동작에는 영향이 없습니다.

## 오픈 일시 지정

년월일과 시분초를 **모두** 지정해야 합니다. 날짜를 비우면 실행되지 않습니다.
헤더의 카운트다운(`D-2일 16:23:00`)으로 해석된 일시를 실행 전에 확인하세요.
오픈 일시가 5분 넘게 지났으면 날짜 오입력으로 보고 실행을 거부합니다.

## 주의

- 개인 예약 편의를 위한 도구입니다. 각 사이트의 이용약관을 확인하고 사용하세요.
- 차량번호 등 개인정보는 저장소에 커밋하지 마세요. 입력값은 브라우저에만 남습니다.
